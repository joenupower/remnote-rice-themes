# Rice Themes

22 unixporn-style color themes for RemNote: Tokyo Night, Gruvbox, Nord, Kanagawa, Catppuccin, Rosé Pine, Everforest and many more. Pick a theme and the whole app follows: sidebar, editor, flashcards, menus and dialogs.

![All 22 themes, one per second](https://raw.githubusercontent.com/joenupower/remnote-rice-themes/main/docs/rice-themes.gif)

## Themes

**Dark:** Tokyo Night (default), Solitude, Retro 82, Nord, Miasma, Hackerman, Everforest, Ethereal, Catppuccin, Gruvbox, Kanagawa, Last Horizon, Lumon, Matte Black, Osaka Jade, Ristretto, Vantablack

**Light:** Lupine, Catppuccin Latte, Flexoki Light, Rosé Pine, White

## Settings

Settings → Plugins → Rice Themes:

- **Theme**: pick one of the 22 themes, or "Off" for RemNote's default look.
- **Monospace font** for a terminal look (default: on). Uses JetBrains Mono, Cascadia Mono or Fira Code if installed, otherwise your system's monospace font. Math formulas keep their own font.
- **Square corners** instead of rounded ones (default: on).

Changes apply within a few seconds, without a reload. A theme looks the same whether RemNote itself is set to light or dark mode.

## Good to know

- Colors that are content stay as they are: color pickers, pen and highlighter colors, drawings and PDF pages.
- In dark themes, highlighted text uses RemNote's dark-mode highlight colors, so it stays readable.
- Text on accent-colored buttons always uses the color that stands out most from the accent.

## Privacy

The plugin runs sandboxed and only uses official plugin APIs. No data leaves RemNote: no network requests, no third-party services.

## Deutsch

**Rice Themes** bringt 22 Farbthemes im Unixporn-Stil nach RemNote, darunter Tokyo Night, Gruvbox, Nord, Kanagawa, Catppuccin und Rosé Pine (17 dunkle, 5 helle). Das Theme färbt die ganze App ein: Seitenleiste, Editor, Lernkarten, Menüs und Dialoge. Dazu gibt es eine Terminal-Schrift (Monospace) und eckige Kanten, beides lässt sich abschalten.

Auswahl unter Einstellungen → Plugins → Rice Themes. Änderungen greifen nach wenigen Sekunden, ohne Neuladen. Farbwähler, Zeichnungen und PDF-Seiten behalten ihre Farben. Es werden keine Daten aus RemNote hinausgeschickt.
